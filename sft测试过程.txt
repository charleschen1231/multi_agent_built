### 第二步：系统构建器 - 创建带 Training 配置的 Multi-Agent 系统

1. 点击顶部导航栏 **"系统构建器"**
2. 在 **System Spec (JSON)** 标签页中，粘贴以下内容：

```json
[
  {
    "agent_id": "planner",
    "model": { "name_or_path": "Qwen/Qwen2.5-0.5B-Instruct" },
    "instruction_prompt": {
      "instruction": "你是 Planner Agent：把用户的数学问题拆分成清晰的解题步骤。",
      "prompt_template": "用户问题：{{input.user_request}}\n请输出详细的解题计划，用步骤1、步骤2...的格式。"
    },
    "input": [{ "from": "user", "key": "user_request" }],
    "output": [{ "key": "plan", "to": [{ "agent": "solver", "as": "plan" }] }],
    "training": {
      "mode": "sft",
      "trainable": true,
      "ground_truth": { "output_key": "plan", "gt_key": "plan_gt" }
    }
  },
  {
    "agent_id": "solver",
    "model": { "name_or_path": "Qwen/Qwen2.5-0.5B-Instruct" },
    "instruction_prompt": {
      "instruction": "你是 Solver Agent：按照计划解决数学问题。",
      "prompt_template": "解题计划：{{input.plan}}\n用户问题：{{input.user_request}}\n请给出详细解答过程和最终答案。"
    },
    "input": [
      { "from": "user", "key": "user_request" },
      { "from": "planner", "key": "plan" }
    ],
    "output": [{ "key": "solution", "to": [{ "agent": "checker", "as": "solution" }] }],
    "training": {
      "mode": "sft",
      "trainable": true,
      "ground_truth": { "output_key": "solution", "gt_key": "solution_gt" }
    }
  },
  {
    "agent_id": "checker",
    "model": { "name_or_path": "Qwen/Qwen2.5-0.5B-Instruct" },
    "instruction_prompt": {
      "instruction": "你是 Checker Agent：检查解答是否正确，给出最终答案。",
      "prompt_template": "用户问题：{{input.user_request}}\n解答过程：{{input.solution}}\n请检查解答是否正确，输出最终答案。"
    },
    "input": [
      { "from": "user", "key": "user_request" },
      { "from": "solver", "key": "solution" }
    ],
    "output": [
      { "key": "final_answer", "to": [{ "user": true }] },
      { "key": "is_correct", "to": [{ "user": true }] }
    ],
    "training": {
      "mode": "sft",
      "trainable": true,
      "ground_truth": { "output_key": "final_answer", "gt_key": "final_answer_gt" }
    }
  }
]
```

3. 输入配置名称：`MathSolver_SFT_Demo`
4. 点击 **"💾 保存配置"**
5. 查看数据流可视化图，确认 planner → solver → checker 的流程

---

### 第三步：数据资产 - 上传训练数据集

1. 点击顶部导航栏 **"数据资产"**
2. 点击 **"➕ 新建数据集"**
3. 输入数据集名称：`MathTrainingData`
4. 选择类型：**训练集**
5. 在文件内容框中粘贴以下内容：

```jsonl
{"user_request": "计算 15 + 27", "plan_gt": "步骤1：识别数字15和27\n步骤2：个位数相加：5+7=12，进位1\n步骤3：十位数相加：1+2+1=4\n步骤4：组合结果：42", "solution_gt": "15 + 27 = 42", "final_answer_gt": "42"}
{"user_request": "求解方程 2x + 5 = 13", "plan_gt": "步骤1：移项\n步骤2：两边减去5\n步骤3：两边除以2", "solution_gt": "2x = 8, x = 4", "final_answer_gt": "x = 4"}
{"user_request": "计算 3 × (4 + 5)", "plan_gt": "步骤1：先算括号内\n步骤2：再进行乘法", "solution_gt": "3 × 9 = 27", "final_answer_gt": "27"}
{"user_request": "求圆的面积，半径r=3", "plan_gt": "步骤1：使用公式S=πr²\n步骤2：代入r=3", "solution_gt": "S = 3.14 × 9 = 28.26", "final_answer_gt": "28.26"}
{"user_request": "将 3/4 转换为小数", "plan_gt": "步骤1：分子除以分母", "solution_gt": "3 ÷ 4 = 0.75", "final_answer_gt": "0.75"}
```

6. 点击 **"保存"**

---

### 第四步：训练工厂 - 创建 SFT 训练任务

1. 点击顶部导航栏 **"训练工厂"**
2. 点击 **"➕ 新建SFT训练任务"**
3. 填写表单：
   - **任务名称**：`MathSolver_SFT_Job_001`
   - **描述**：`System-level SFT 训练演示`
   - **选择配置**：选择刚才创建的 `MathSolver_SFT_Demo`
   - **可训练 Agents**：会显示 planner, solver, checker
   - **选择数据集**：选择 `MathTrainingData`
   - **数据来源**：选择 **"从轨迹生成"**
   - **学习率**：`2e-5`
   - **训练轮数**：`3`
   - **Batch Size**：`4`
   - **Max Length**：`2048`
4. 点击 **"创建训练任务"**

---

### 第五步：监控训练进度

1. 在训练任务列表中，查看刚创建的任务
2. 状态会从 **"⏳ 等待中"** → **"🔄 运行中"** → **"✅ 已完成"**
3. 点击任务行的 **"查看"** 按钮，可以查看：
   - 任务详情
   - 超参数
   - 训练日志
   - 训练指标

---

### 第六步：部署训练好的模型

1. 训练完成后，在任务详情页面会显示 **"🎉 训练完成"**
2. 点击 **"🚀 部署模型到配置"** 按钮
3. 确认部署后，模型路径会自动更新到配置中
4. 系统会创建一个新版本的配置（原配置名 + `_deployed`）

---

### 第七步：测试微调后的模型

#### 方式1：在训练详情页面直接测试
1. 在训练完成后的详情页面，点击 **"🧪 测试微调后模型"**
2. 输入测试问题，例如：`计算 25 + 36`
3. 查看执行结果，包括：
   - 每个 Agent 的执行步骤
   - 最终结果

#### 方式2：在执行中心测试
1. 点击顶部导航栏 **"执行中心"**
2. 选择部署后的配置（带有 `_deployed` 后缀的）
3. 输入测试问题
4. 点击 **"执行"**
5. 对比微调前后的效果
