系统构建器

JSON定义 → 自动解析 → 可视化生成

System Spec (JSON)
分支/循环配置
ℹ️
点击"解析并生成"校验 JSON 配置并生成数据流图
✅
分支/循环功能已启用！请在 JSON 中配置 type: "branch" 或 type: "loop_controller"

分支配置示例

{
  "agent_id": "router",
  "type": "branch",
  "input": [...],
  "branches": {
    "conditions": [
      {
        "condition": "{{input.score}} >= 8",
        "target": "high_quality_handler",
        "output_mapping": {...}
      },
      {
        "condition": "{{input.score}} >= 5",
        "target": "medium_quality_handler"
      }
    ],
    "default": "low_quality_handler"
  }
}

循环配置示例

{
  "agent_id": "refiner",
  "type": "loop_controller",
  "input": [...],
  "loop": {
    "max_iterations": 3,
    "condition": "{{input.quality}} < 8 && {{input.iteration}} < 3",
    "on_continue": {
      "output": {"iteration": "{{input.iteration}} + 1"},
      "next": "generator"
    },
    "on_exit": {
      "output": {"final_result": "{{input.result}}"},
      "next": "output_finalizer"
    }
  }
}
ℹ️
支持的条件表达式：{{input.xxx}} > 5, {{input.flag}} == true, &&, ||
